Dark real estate theme with a home page, a searchable Properties page and a Property Details page.

== Description ==

Esnine is built from the Estatein real estate design. Properties, testimonials and FAQs are custom post types. All site text is edited through Advanced Custom Fields on the static home page.

The Advanced Custom Fields plugin is required.

== Installation ==

1. Install and activate Advanced Custom Fields.
2. Upload the theme folder to wp-content/themes/ and activate it.
3. Set Settings > Permalinks to "Post name".
4. Create a page, set it as the static home page under Settings > Reading, and fill in its fields.
5. Assign menus to the "Primary Menu" and "Footer Menu" locations.

The full guide is in docs/installation.md.
