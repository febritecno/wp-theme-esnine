# Esnine

A dark real estate theme for WordPress, built from the Estatein design. It has a home page, a searchable Properties page and a Property Details page with gallery, pricing breakdown and inquiry form.

Properties, testimonials and FAQs are post types. Every text, image and link on the site is edited in the WordPress admin.

## Requirements

- WordPress 6.0 or newer
- PHP 7.4 or newer
- The Advanced Custom Fields plugin (free version)

## Quick start

1. Copy the `esnine` folder to `wp-content/themes/`.
2. Install and activate the plugins listed in [docs/installation.md](docs/installation.md).
3. Activate the theme under Appearance > Themes.
4. Create a page called "Home" and set it as the static home page under Settings > Reading.
5. Edit the Home page and fill in the fields.
6. Add properties, testimonials and FAQs.

A new site starts empty. A section appears once it has content, so the home page fills in as you work through the steps.
